# Commons Explorer

Commons Explorer — a module of the Commons Platform (India). UI design prototype built as a single HTML file.

## Preview

- **UI Design (current):** https://ravi26design.github.io/Commons-Explorer/
- **v1 wireframe (grayscale, structure-first):** https://ravi26design.github.io/Commons-Explorer/commons-explorer-wireframe-v1-backup.html

## Files

| File | Purpose |
| --- | --- |
| `commons-explorer-wireframe.html` | High-fidelity UI design (sage green / gold / cream design language, Lato + DM Serif Display, Leaflet map) |
| `commons-explorer-wireframe-v1-backup.html` | Earlier low-fidelity wireframe kept for reference |
| `assets/` | Photos, maps, charts and illustrations used by the prototype |
| `index.html` | Redirects to the UI design |

## Run locally

Open `commons-explorer-wireframe.html` in a browser. No build step is required.
